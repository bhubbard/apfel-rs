# Getting Support for apfel-rs

Thank you for using `apfel-rs`! This document will guide you to the right place to get help or ask questions.

---

## Which Channel to Use?

### 1. Bug Reports
If you found unexpected behavior, a crash, panic, or bug:
- Search existing [Issues](https://github.com/bhubbard/apfel-rs/issues) to see if it has already been reported.
- If not, open a Bug Report using the repository's issue form.

### 2. Feature Requests & Proposals
If you have an idea for a new capability, enhancement, or optimization:
- Open a Feature Request issue.
- Provide concrete use cases and rationale.

### 3. Security Vulnerabilities
If you discover a security vulnerability:
- **Do not use public GitHub issues.**
- Please refer to our [Security Policy](SECURITY.md) for private reporting instructions.
