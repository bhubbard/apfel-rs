Architecture & Features

Built for Performance, Privacy & Simplicity

Everything you love about Apple Intelligence, wrapped in a UNIX-first Rust binary that fits in your pocket.

🔒

100% On-Device & Private

Executes completely against macOS FoundationModels on Apple Silicon. Zero network calls, zero telemetry, zero tokens leaking outside your machine.

⚡

OpenAI-Compatible Daemon

Drop-in replacement for OpenAI endpoints. Provides /v1/chat/completions with streaming SSE, /v1/responses, /v1/models, and /health.

🛠️

Model Context Protocol (MCP)

Integrates directly with external MCP servers over stdio. Automatically negotiates tools, invokes scripts, and runs the self-healing re-prompting loop.

🧠

5 Context Trimming Strategies

Fine-tune conversation budgets with sliding-window, newest-first, oldest-first, summarize, or strict overflow protection.

🛡️

Hardened Localhost Security

DNS rebinding and CSRF prevention, strict Origin header verification, constant-time Bearer token checks, and sanitized subprocess environments.

🍏

macOS Login Daemon

Manage seamlessly via Homebrew. Run brew services start apfel-rs to launch on login on 127.0.0.1:32185 with automated log rotation.

Drop-in OpenAI Compatibility

Use Your Favorite Tools & SDKs

Point any OpenAI-compatible app, Cursor, Open WebUI, Python script, or TypeScript SDK directly to http://127.0.0.1:8080/v1. 

# POST /v1/chat/completions with SSE Streaming
curl -N -X POST http://127.0.0.1:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "apple-foundationmodel",
    "stream": true,
    "temperature": 0.7,
    "messages": [
      {"role": "system", "content": "You are a concise engineering assistant."},
      {"role": "user", "content": "How does Rust guarantee thread safety?"}
    ]
  }'
UNIX Ergonomics

Command-Line Reference

Powerful flags designed to pipe with cat, jq, and standard shell utilities.

Command / Flag Description Example Usage
apfel <PROMPT> Standard single-shot completion apfel "Explain DNS in one sentence"
--stream Real-time SSE token stream to stdout apfel --stream "Draft a quick release note"
-f, --file <PATH> Attach text, pdf, or image files into context apfel -f src/lib.rs "Summarize the exports"
--code Extract only the first markdown code block apfel --code "Write a Python script to parse JSON"
--chat Interactive REPL with slash commands (/info, /clear) apfel --chat
--serve Run the OpenAI-compatible HTTP server apfel --serve --port 8080
--mcp-server <CMD> Attach external stdio MCP server for tool calls apfel --mcp-server "./calc_mcp.py" "What is 42 * 10?"
--count-tokens Accurately measure tokens before executing apfel --count-tokens -f long_doc.txt
--benchmark Execute internal throughput and latency stress test apfel --benchmark
Deep Dive

System Architecture

How apfel-rs bridges the macOS C-ABI with zero serialization overhead and predictable memory bounds.

Input Ingress

CLI & Axum HTTP

Piped stdin, CLI args, or /v1/chat/completions REST / SSE endpoints.

Rust Core

Session Engine

Sliding window context trimmer, token budgeter, MCP tool loop, and security guards.

Inter-Op Bridge

Swift C-ABI

Zero-copy C-ABI bridge providing memory safety between Rust FFI and Swift actors.

Apple Silicon

FoundationModels

macOS on-device SystemLanguageModel running locally on Apple Neural Engine / GPU.

Extensibility

Model Context Protocol (MCP)

Equip Apple Intelligence with live external tools—from calculators to web search and database engines.

⚙️

Automatic Tool Discovery

Launches any stdio MCP server (Python, Node.js, Go, or native executable) and negotiates JSON-RPC schemas automatically.

🔄

Self-Healing Reprompt Loop

When the model triggers a tool call, apfel-rs executes the tool, feeds the output back into context, and reprompts for the final answer.

🛡️

Process Isolation

Subprocesses run with scrubbed environment variables to prevent API token or credential leaks to external tools.

Developer Reference

Exit Codes

Standardized POSIX exit codes for predictable shell script automation.

Code Constant Meaning
0 SUCCESS Successful completion
1 RUNTIME_ERROR Internal runtime failure or Swift FFI exception
2 USAGE_ERROR Invalid arguments or malformed JSON input
3 GUARDRAIL System safety guardrail triggered
4 CONTEXT_OVERFLOW Prompt exceeds context budget with strict strategy
5 MODEL_UNAVAILABLE Apple Intelligence disabled or model not downloaded
6 RATE_LIMITED System capacity exhausted
7 NO_CODE --code requested but no code block returned
