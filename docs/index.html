Command-Line Reference

--benchmark Execute internal throughput and latency stress test apfel --benchmark

Frequently Asked Questions

Everything You Need to Know

Common questions regarding architecture, privacy, compatibility, and setup.

What is apfel-rs and how does it use Apple Intelligence? ▼
apfel-rs is a complete, native Rust implementation and high-performance fork of the original Swift apfel. It bridges directly into Apple's macOS FoundationModels framework on Apple Silicon to execute on-device LLM inference without any cloud latency or telemetry.
Does apfel-rs require an internet connection or cloud API keys? ▼
No. apfel-rs is 100% on-device. All inference runs locally through Apple Neural Engine / GPU cores. Zero data ever leaves your Mac, and no OpenAI or third-party subscription keys are needed.
How does apfel-rs achieve a 3.76x speedup over the Swift version? ▼
By migrating the HTTP server from Swift's Hummingbird to Rust's axum and tokio runtime, optimizing token counting with zero-allocation buffers, eliminating Swift runtime GC/pause jitter, and interfacing with Swift via a lean, zero-overhead C-ABI bridge.
Can I use apfel-rs as a drop-in local OpenAI backend in Cursor or Open WebUI? ▼
Yes! Start the server with apfel --serve --port 8080 (or run brew services start apfel-rs). Configure your client's OpenAI Base URL to http://127.0.0.1:8080/v1. Any arbitrary string can be passed for the API key.
What hardware and macOS versions are supported? ▼
You need an Apple Silicon Mac (M1, M2, M3, M4, or later) running macOS Sequoia 26.0 or higher with Apple Intelligence enabled in System Settings.
How does Model Context Protocol (MCP) tool execution work? ▼
Pass --mcp-server <COMMAND> to attach an external MCP tool server over standard input/output. apfel-rs performs JSON-RPC capability negotiation, presents tool definitions to the FoundationModel, runs tool calls in an isolated sanitized environment, and re-prompts the model with execution outputs until completion.
How do I run apfel-rs as an automatic login daemon? ▼
If installed via Homebrew, simply execute brew services start apfel-rs. Homebrew installs a launchd plist that starts the daemon automatically upon macOS user login on 127.0.0.1:32185.
